# Metric list v1 (draft)

**Question.** What should replace the v0 metric conventions: units, clusters, intervals, and how a distribution study states its question?

**Result.** A draft, not frozen. Top-1 success stays the only primary metric; v1 adds units, clusters, which interval decides and when a difference is worth acting on, and judges collapse and confidence by the question asked.

**Files.**
- `METRIC_LIST_v1_DRAFT.md` : the current draft; `.first.md`, `.before-flags.md`, `.before-a2.md` are earlier versions.
- `CHANGELOG.md` : what changed after review.
- `FACTCHECK.md` : the numbers checked against sources.
- `A2_UPDATE.md` : the update from the confidence probe.

**Reproduce.** Notes only; no scripts.

**Data.** None.
